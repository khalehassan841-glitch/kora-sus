# KORA SUS — نسخة تجريبية جاهزة للنشر المجاني

مشروع لعبة اجتماعية كروية 3D تعمل من المتصفح، مع إنشاء رومات بكود، دخول اللاعبين، اختيار شخصية، جاهزية، وحركة متعددة اللاعبين بشكل أولي.

## نشر اللعبة من موبايل أندرويد فقط

### 1) فك ضغط الملف
نزّل ملف ZIP وفك ضغطه من تطبيق الملفات في الموبايل. لازم يظهر مجلد `kora-sus` وفيه `package.json` و`server.js` و`render.yaml` ومجلد `public`.

### 2) ارفع المشروع إلى GitHub
1. افتح https://github.com وسجّل دخولك أو أنشئ حسابًا مجانيًا.
2. أنشئ Repository جديدًا باسم `kora-sus`، واختَر Public، ثم Create repository.
3. ارفع الملفات مع الحفاظ على نفس ترتيب المجلدات. أسهل طريقة من متصفح/مدير ملفات يسمح برفع مجلد كامل. إن لم يسمح الهاتف برفع مجلد كامل، أنشئ مجلد `public` داخل المستودع وارفع ملفات مجلد `public` داخله؛ ثم ارفع ملفات الجذر (`package.json`, `server.js`, `render.yaml`, `.gitignore`, `README.md`) إلى جذر المستودع.
4. تأكد أن `server.js` و`package.json` و`render.yaml` في الجذر، وأن `index.html` و`app.js` و`style.css` و`manifest.webmanifest` و`sw.js` ومجلد `icons` داخل `public`.

### 3) انشرها مجانًا على Render
1. افتح https://render.com وسجّل بحساب GitHub.
2. من لوحة التحكم اختَر **New → Blueprint**.
3. اختَر مستودع `kora-sus` ووافق على الإعدادات الموجودة في `render.yaml`.
4. اختَر الخطة المجانية إذا طُلب منك ذلك، ثم أنشئ الخدمة وانتظر انتهاء النشر.
5. افتح رابط `onrender.com` الذي يعطيك Render. أول فتح بعد فترة خمول قد يحتاج قرابة دقيقة حتى يصحى السيرفر.

## تثبيتها كأنها تطبيق
بعد النشر، افتح رابط اللعبة في Chrome على أندرويد، ثم قائمة ⋮ واختَر **إضافة إلى الشاشة الرئيسية** أو **تثبيت التطبيق** إذا ظهر الخيار.

## التشغيل محليًا
يتطلب Node.js 18 أو أحدث:
```bash
npm install
npm start
```
ثم افتح `http://localhost:3000`.

## مهم قبل مشاركة الرابط
- الخطة المجانية في Render قد توقف الخدمة بعد 15 دقيقة من عدم وجود زيارات/اتصالات، وقد تستغرق حوالي دقيقة لتبدأ مجددًا. حدود الخدمة المجانية قابلة للتغيير.
- الغرف محفوظة في ذاكرة السيرفر فقط؛ إذا أعيد تشغيله أو نام، قد تختفي الغرف الحالية.
- هذه نسخة Prototype: تتضمن لوبي ورومات ومزامنة حركة تجريبية، لكنها لا تتضمن بعد نظام اجتماعات وتصويت كاملًا أو مهام نهائية أو صوت/مايك. الشخصيات مجسمات كرتونية مبسطة وليست نماذج واقعية للاعبين.
- Three.js والخط الخارجي يحتاجان اتصال إنترنت. تثبيت الموقع كتطبيق لا يجعله يعمل أوفلاين بالكامل.
- لا تحتاج بطاقة دفع لبدء التجربة على الخطة المجانية، لكن راجع أي شاشة دفع قبل تأكيد أي اختيار.
